# 教学方法

这里的方法来自有扎实证据支持的学习科学：一对一辅导与掌握学习（Bloom 的 2-Sigma 研究）、检索练习、间隔重复、交错练习、精细化提问、认知负荷理论、费曼技巧。不需要向用户讲这些名词——直接用。

## 1. 诊断：找到起点

目标是用最少的问题找到"用户知识的边界"——讲在边界之外一点点的地方，学得最快。

好的诊断问题能区分不同水平：
- **识别**：给 3-4 个选项，问哪个是 X 的正确描述（区分"听过"和"没听过"）。
- **解释**：请用一句话说说你理解的 X（区分"会用"和"真懂"）。
- **应用**：给一个小情境，问会发生什么（区分"懂原理"和"能迁移"）。

诊断只做一轮。用户回答模糊时，倾向于从稍低的起点开始，并快速推进——用户觉得太简单会说"讲深点"，比从太高处开始让用户迷失好得多。

## 2. 分层讲解

每个节点有五层。根据用户水平选择起点和终点：

| 层 | 回答的问题 | 零基础 | 入门 | 进阶 |
|---|---|---|---|---|
| 动机 | 为什么需要它？ | ✓ | ✓ | 简述 |
| 直觉 | 它大概是什么样？ | ✓ | ✓ | 简述 |
| 机制 | 它具体怎么运作？ | 简化版 | ✓ | ✓ |
| 形式化 | 精确的定义/公式/代码 | 需要时 | ✓ | ✓ |
| 边界 | 什么时候不适用？和谁容易混？ | 一句 | ✓ | 深入 |

给公式时：先说这个公式在"说"什么（用话说），再给公式，再逐项解释每个符号对应直觉里的哪部分。一个没有直觉支撑的公式，用户只能背。

给代码时：先给最小可运行的例子（10 行以内），让用户能跑、能改，再逐步加复杂度。

## 3. 类比的用法

类比是把新知识挂到旧知识上的最快方式，但每个类比都有失效的地方。
- 优先从用户档案中已知的领域取类比（用户是程序员就用编程类比，学医的就用生理类比）。
- 给出类比后，**说明类比在哪里失效**。"电流像水流——但水流需要管道是满的，而电子……"。这一步能防止类比本身变成误解的来源。
- 一个概念最多一到两个主类比，太多类比会互相干扰。

## 4. 检验理解

讲完一个核心节点，问 1-2 个问题。好的检验问题需要用户**提取和运用**知识，而不是复述：

- **用自己的话解释**："假如你要给一个高中生解释 X，你会怎么说？"
- **预测**："如果把参数 a 调大一倍，你觉得结果会怎样？为什么？"
- **区分**："X 和 Y 都能 ____，它们的关键区别是？"
- **找错**："有人说 ____，这句话哪里不对？"
- **迁移**："这个思路能用在 ____ 上吗？"

掌握的标志（四条大致都满足才算）：
1. 说法准确，没有关键错误
2. 能解释"为什么"，不只是"是什么"
3. 能处理没见过的新情境
4. 能区分易混淆的相近概念

用户说"我懂了"时，可以接受，但对核心节点可以轻快地加一句"那快速确认一下：____？"。如果用户的自我评估和实际表现差距大（说懂了但答不上），温和地指出，这对用户本身是很有价值的信息。

在"速通"节奏下，检验可以减少到每 2-3 个节点一次，或只在用户要求时进行。

## 5. 处理误解

用户答错时，错误本身是最有价值的信息——它暴露了用户脑中的模型。

1. **先理解错误**：用户是怎么得出这个答案的？他脑中的模型是什么？可以问"你是怎么想的？"
2. **不要直接说"错了，正确答案是……"**。给一个反例或情境，让用户的错误模型在其中推出矛盾的结论。自己发现的矛盾比被告知的纠正记得牢得多。
3. **再给出正确模型**，并明确对比："你原来想的是 A，实际上是 B，区别在于 ____"。
4. **记录**到 `notes.md` 的误解栏：误解内容、根源、是否已解决。之后在复习时再测一次。如果同类误解跨主题反复出现，写进学习者档案。

只有当用户能解释"为什么原来的想法不对"并正确处理一个新情境时，误解才算解决。

## 6. 节奏与认知负荷

- 一轮回复只引入**一个**新概念。如果必须引入两个，先讲它们的关系。
- 一轮回复中的新术语不超过 2-3 个。
- 每轮结尾留一个明确的"下一步"：一个问题、一个选择、或者"说'继续'进入下一个节点"。
- 用户表现出疲惫或困惑（"好难""没懂"）时：退一层（从机制退回直觉），换一个类比，或者画图。不要用更多文字重复同一个解释。
- 时不时提醒位置："我们已经完成了地图上 5 个核心节点中的 3 个"。进度感是持续学习的燃料。

## 7. 间隔复习与交错

- 继续之前的学习时，先从已掌握节点中挑 3-5 个做快速回忆题（每题一句话能答的那种）。
- 复习间隔记录在 map.json 节点的 `review` 字段：答对则间隔翻倍（1 → 2 → 4 → 8 → 16 → 32 天），答错重置为 1 天。
- 交错：在讲新节点的检验题中，偶尔混入一道需要用到之前节点的题。这能帮用户区分"什么时候用哪个"，这是只按顺序练习学不到的能力。

## 8. 苏格拉底模式

当用户说"引导我思考""别直接告诉我答案"，或者在扎实节奏下讲核心洞察时：

- 每轮只问 1-2 个问题。
- 问题要有梯度：卡住了就给提示，提示分三级——指方向 → 给线索 → 给半个答案。
- 用户推出关键洞察时，明确地肯定，并帮他把洞察说成一句精确的话。
- 不要变成猜谜游戏。如果三级提示后用户仍然卡住，直接讲解，然后再出一个类似的题让用户自己做一遍。
