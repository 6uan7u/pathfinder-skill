# 学习者档案模板

保存在 `~/.pathfinder/profile.md`（用户主目录下，不放在某个 agent 的配置目录里，所以 Claude Code、Codex 等不同 agent 能共享同一份档案），跨项目、跨主题共享。第一次使用时创建，每次学习结束时更新。

记录原则：
- 只写**对未来的讲解有指导作用**的信息。"学过傅里叶变换"本身没用，"懂傅里叶变换，可以用它做类比来讲小波/卷积"有用。
- 行为模式要出现两次以上再写，避免被一次偶然表现误导。
- 保持在 80 行以内。旧的、被新信息推翻的条目要删除，而不是累加。
- 用户可以直接编辑这个文件，尊重用户的修改。

```markdown

- 回复长度：
- 其他：

## 反复出现的误区模式
- （例：容易混淆充分条件与必要条件——在逻辑相关内容中主动区分）
```
